Finance Dashboard

Interactive Power BI Dashboard Project

Project Overview

This dashboard has been developed using Microsoft Power BI to analyze financial performance through interactive visualizations. It includes KPI Cards, Sales Analysis, Profit Analysis, COGS, Units Sold, Charts, Slicers and Navigation.

Dashboard Preview

Key Features

📊 KPI Cards

Total Sales, Profit, COGS and Units Sold

📈 Sales Analysis

Monthly Sales Performance Visualization

💰 Profit Analysis

Product-wise Profit Comparison

🌍 Country Analysis

Interactive Country-wise Sales Report

🎛 Interactive Filters

Year, Country, Segment and Product Slicers
